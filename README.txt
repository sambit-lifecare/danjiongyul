단지온 v2.6 — GitHub 업로드용 화면 체험 버전

관리사무소: 82619473
방역관리: 73948261
각 버튼을 누른 뒤 숫자 비밀번호를 입력하면 해당 화면이 열립니다.
입주민은 비밀번호 없이 이용합니다.
온키 마스코트, 전국 아파트 데이터, 신청 최종 확인 포함.

중요: GitHub Pages 정적 사이트의 비밀번호는 소스코드에 공개됩니다.
이는 화면 체험용이며 실제 인증/접근통제 기능이 아닙니다.
신청 기록은 방문한 기기의 브라우저에만 저장되고, 관리사무소에 전달되지 않습니다.
실제 주민 동·호수, 연락처, 민감정보를 입력하거나 서비스 운영에 사용하지 마세요.
실제 서비스는 별도의 서버 인증, 단지별 권한, 비공개 DB가 필요합니다.

ZIP 압축 해제 후 모든 파일을 저장소 루트에 업로드하세요.
기존 사이트가 이전 화면을 표시하면 새로고침 또는 사이트 데이터 삭제를 확인하세요.
